How to disable Chrome auto-update

The portable Chrome for Testing builds downloaded here do not auto-update — they stay at the version you chose. The steps below only apply to a normally installed Chrome.

Chrome auto-updates in the background, which will replace a pinned version. Disable it per OS below.

Windows

  1. Press Win + R, run services.msc.
  2. Find Google Update Service (gupdate) and Google Update Service (gupdatem).
  3. Right-click each, choose Properties, set Startup type to Disabled, then Stop.

Or via registry (admin): create DWORD AutoUpdateCheckPeriodMinutes = 0 under HKLM\SOFTWARE\Policies\Google\Update.

macOS

  1. Quit Chrome.
  2. Rename the updater folder: ~/Library/Google/GoogleSoftwareUpdate → GoogleSoftwareUpdate.bak.

Or run: defaults write com.google.Keystone.Agent checkInterval 0

Linux

  • Debian/Ubuntu: sudo apt-mark hold google-chrome-stable
  • Fedora/RHEL: sudo dnf versionlock google-chrome-stable
